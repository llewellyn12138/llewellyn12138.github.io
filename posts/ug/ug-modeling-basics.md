# UG (NX) 建模入门：从草图到实体

记录一下自己从零摸 UG 的过程。不追求大而全，只写实际用得上、并且踩过坑的部分。

---

## 1. 基本流程

UG 的建模思路非常一致，绝大多数零件都走这条线：

```
新建文件 → 进入草图 → 画轮廓并约束 → 完成草图 → 拉伸/旋转成实体 → 细节（倒角/圆角/孔）→ 保存
```

新手最容易卡住的不是命令，而是**草图的约束**。约束没做全，后面一改尺寸整个模型就散。

## 2. 草图是地基

### 完全约束

草图必须做到**完全约束**（状态栏显示 "完全约束"），否则：

- 拉伸出的实体尺寸不稳定；
- 后续修改参数时轮廓会乱跑；
- 装配时出现莫名其妙的干涉。

常用约束快捷键：

| 约束 | 作用 | 说明 |
| --- | --- | --- |
| 几何约束 | 平行/垂直/相切/同心 | 先约束几何关系，再标尺寸 |
| 尺寸约束 | 标注长度/角度/半径 | 最后一步再加尺寸 |
| 自动约束 | 自动推断 | 方便但容易加多余的约束 |

**原则：先几何后尺寸。** 顺序反了会不断报"过约束"。

### 少用"转换参考"

新手常把不想动的东西全转成参考线，结果草图变成一坨。更稳的做法是：

- 需要的轮廓才画；
- 辅助线用构造线（转为参考）而不是额外画实体线。

## 3. 拉伸与布尔

拉伸是最常用的特征。几个要点：

- **布尔运算**默认是"求和"，做切除时要选"求差"；
- 拉伸方向可以反向，注意 `反向` 按钮；
- **拔模角**在拉伸对话框里直接设置，比事后加拔模特征更稳。

```text
拉伸 → 选择曲线 → 指定矢量（Z 轴）→ 输入距离 → 布尔：求和/求差 → 确定
```

布尔运算失败是最常见的报错，通常原因：

1. 两个实体只是**相切**而不是真正相交；
2. 曲面精度问题（把公差调大一点）；
3. 草图有微小开口或重叠。

## 4. 圆角与倒角的顺序

**先倒角后圆角**，或者干脆放到最后统一处理。原因：

- 圆角对相邻面的拓扑很敏感；
- 先做圆角再开孔，孔边缘会把圆角切断，出现破面。

如果圆角失败，尝试：

- 减小半径；
- 改"边倒圆"为"面倒圆"；
- 分几次做，而不是一次性选所有边。

## 5. 装配的几个习惯

- 每个零件单独一个文件，不要在装配体里直接建模；
- 用**装配约束**（同心/接触/距离）而不是移动到位再固定；
- 命名规范：`零件名_版本.prt`，否则零件多了完全找不到。

## 6. 常用快捷键（个人习惯）

| 操作 | 快捷键 |
| --- | --- |
| 拉伸 | X |
| 草图 | S 然后输入 sketch |
| 测量 | Ctrl+M 之后选测量 |
| 显示/隐藏 | Ctrl+W |
| 适合窗口 | Ctrl+F |

> 快捷键可以在 `工具 → 定制 → 键盘` 里自己改，不必记默认的。

## 7. 踩过的坑

- **中文路径**：UG 对中文路径兼容性差，工程目录尽量全英文；
- **保存版本**：UG 默认不自动保存，崩溃一次能丢一小时，务必开自动保存；
- **单位**：新建文件时确认是毫米，改单位很麻烦；
- **导入 STEP**：导入后是"无参数实体"，不能改尺寸，只能重新建模。

UG 的学习曲线主要卡在**草图约束**和**布尔运算失败**这两处。把这两块练熟，剩下的命令边用边查就行。
